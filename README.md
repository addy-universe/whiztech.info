# WhizTech — Enterprise IT Solutions, AI Automation & Government Projects

High-end, responsive landing page for **WhizTech**, an enterprise IT infrastructure, AI automation, and government solutions firm based in Edmonton, Alberta, Canada.

---

## ⚡ Tech Stack & Architecture

- **Core:** Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom Design System with CSS Tokens)
- **Design Language:** True OLED Pure Black (`#000000`), Electric Blue (`#1d63ed`), Cyan (`#06b6d4`), and Slate (`#94a3b8`)
- **Typography:** Outfit (Luxury Geometric Tech) & Inter
- **Micro-Interactions & Effects:**
  - Dynamic Mouse-Tracking Border Spotlight (Linear / Raycast Style)
  - Hardware-Accelerated Ambient Cursor Halo
  - Zero-Gravity Floating Cloud Architecture Terminal Hub
  - Live Telemetry Micro-Fluctuations (Simulated Latency & Throughput)
  - Periodic Luxury Light Sheen on Primary Action CTAs
  - Smooth Staggered Scroll Reveal via IntersectionObserver
  - Quick-Action Floating Back-to-Top Button
  - Simulated Cloudflare Turnstile Human Verification on Intake Form
  - Interactive Consultation Booking & Compliance Legal Modals

---

## 🚀 Running Locally

You can serve the static site using any local HTTP server or the included lightweight Node.js script:

```bash
# Using Node.js
node server.js
```

Then visit `http://localhost:3000/` in your browser.
